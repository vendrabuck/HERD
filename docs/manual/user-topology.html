User track - Step 3

Building a topology

The topology editor is a canvas where you draw how your lab is wired: drag devices on, connect them, and HERD checks every link against the real physical cabling. It's the signature feature — and it's less scary than it looks.

What a topology is, in one breath

A saved diagram of which devices are connected to which, at which network layer. You build it once, then hand it to a reservation. Green links mean "this path physically exists." Red links mean "it doesn't — fix it before you reserve."

Getting there

Opening the editor

Click Topology in the nav, then either pick a saved topology or hit New topology. You land on a dotted canvas with a floating palette in the corner and a toolbar across the top.

  1. The equipment palette. Your draggable devices. Covered next.
  2. A device node. One piece of equipment on the canvas. A yellow ring means it's selected.
  3. Edge-layer switch (L1 / L2 / L3). Sets which layer new connections are drawn at, and which layer's edges are highlighted.
  4. Use AI. Describe a lab and let Claude propose the wiring. Only appears if your admin enabled it — see the AI guide.
  5. Reserve Topology. Turns this diagram into a reservation. Disabled while any edge is red.

Your parts bin

The equipment palette

The floating panel in the corner lists every DUT (Management-type device) you can see. Drag it by its title bar; collapse it with the −.

  • Only DUTs appear here. Infrastructure switches (L1/L2/L3) are wired in automatically by the routing system — you never drag them by hand.
  • Already-reserved exclusive devices are hidden by default. Flip Show reserved resources to include them.
  • Devices already on the canvas disappear from the palette. Delete a node and it comes back.
  • Search matches device name and field values (passwords and login fields excluded).
Palette completely empty?

You have no device visibility yet. That's the same permissions gap from first boot — ask an admin to add your user group to a device group, then reload.

Putting gear down

Adding devices

Drag a device card from the palette onto the canvas

It drops in as a node with its name, a small type glyph, and a PHYSICAL or CLOUD badge.

Drag the node to position it

Layout is yours. Positions are saved with the topology, so it reopens exactly as you left it.

Dropping the same device twice does nothing

HERD silently prevents duplicates — one node per device, always.

"Can't drop the device here"

You're trying to mix a PHYSICAL device with a CLOUD one in the same topology. HERD won't allow it — physical and cloud can't share a diagram. Make a separate topology for each type.

Wiring it up

Drawing connections

Drag from one device's handle (the little dot on its edge) to another's. A connection dialog opens.

  1. Layer. What kind of link this is. L2 and L3 are logical overlays; they still need a real physical path underneath to count.
  2. Port on each device. The dropdowns list every port. A (no cable) suffix warns that the port has no physical cabling recorded — pick another or it'll go red.
  3. Create. Adds the edge. HERD immediately checks it against the cabling graph and colours it.

The part everyone asks about

Red vs green edges

Every edge gets checked against the real physical cabling. The badge on the edge tells you the verdict. Here's the full vocabulary:

What you seeWhat it meansWhat to do
Green + "N hops"A route exists through the switch infrastructure. N is the hop count.Nothing — you're good.
Red + "no path"No route between the two devices. They're in isolated fabrics, or switches between them are missing from inventory.See callout below.
Red + "uncabled port"One of the chosen ports has no physical cable recorded. Beats the path check.Pick a cabled port, or ask an admin to record the cabling.
No badge yetThe check is still resolving.Wait a beat; it'll settle.
A red edge blocks reservation

The Reserve Topology button is disabled while any edge is red — and the server enforces the same rule, so you can't sneak past it via the API. A red L1 edge usually means no physical cabling connects the two DUTs, or the switches between them aren't in inventory. Both are an admin cabling fix, covered in Cabling things up.

I need a link between two physically isolated labsadvanced

For something like an MPLS tunnel between two sites that share no cabling, add a virtual device representing the tunnel and cable it into both fabrics (in the cabling service). The validator then sees a real path and the edge goes green. This is an admin task.

Keeping your work

Saving & version history

Click Save in the toolbar

The first save asks for a topology name. After that, Save just updates it.

Every meaningful save is a new version

Open the History sidebar to see the list (newest first) with author and timestamp. Preview any version read-only; Compare two to see Added / Removed / Modified; Restore to roll back.

Restore is blocked while an active or pending reservation still references the topology. Cancel or wait for it to release, then restore.

Keyboard & mouse cheat sheet
  • Pan: drag empty canvas
  • Select: click a node - Multi-select: shift-click or drag a box
  • Delete selected: Delete or Backspace
  • Connect: drag from a node handle to another node
  • Zoom: mouse wheel, or the + / − buttons by the minimap
